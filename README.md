# Langkah Juara

Aplikasi catur adaptif berbahasa Indonesia untuk anak dan pemula. Pemain dapat belajar melalui materi singkat, bermain melawan bot Stockfish, mendapatkan peringatan kesempatan kedua, dan melihat perkembangan yang tersimpan di perangkat.

## Halaman utama

- `index.html` — beranda dan ringkasan progres
- `games/chess.html` — arena catur melawan lima karakter bot
- `belajar.html` — jalur enam materi catur
- `pelajaran.html` — materi visual dan kuis interaktif
- `profil.html` — profil lokal, statistik, dan pengaturan
- `riwayat.html` — hasil pertandingan terakhir

## Teknologi

HTML, CSS, JavaScript, chess.js, chessboard.js, Stockfish, localStorage, dan PWA service worker. Tampilan dirancang untuk handphone, tablet, Chromebook, dan laptop.

## Menjalankan

Buka melalui GitHub Pages atau server lokal. Service worker dan Stockfish memerlukan halaman yang disajikan melalui HTTP/HTTPS, bukan langsung dari `file://`.
